# datagovgr-ai-readiness

Ποιότητα και ετοιμότητα για Τεχνητή Νοημοσύνη (ΤΝ) των ανοιχτών δεδομένων του [data.gov.gr](https://data.gov.gr/).

Πρακτική άσκηση του ΠΜΣ «Ηλεκτρονική Διακυβέρνηση» του Πανεπιστημίου Αιγαίου στον Οργανισμό Ανοιχτών Τεχνολογιών (ΕΕΛΛΑΚ / GFOSS), με επιβλέποντα τον κ. Αλέξανδρο Μελίδη. Οκτώβριος – Δεκέμβριος 2026.

> **English:** Quality and AI-readiness assessment of the open datasets published on data.gov.gr, Greece's national open data portal. Internship project at the Open Technologies Alliance (GFOSS), October–December 2026.

## Τι κάνει αυτό το έργο

- Αξιολογεί δείγμα 36 συνόλων δεδομένων του data.gov.gr σε τρία επίπεδα: ποιότητα, μεταδεδομένα και νομικό καθεστώς, ετοιμότητα για ΤΝ.
- Ελέγχει αν τα σύνολα υψηλής αξίας τηρούν τον Εκτελεστικό Κανονισμό (ΕΕ) 2023/138.
- Δείχνει ποια σύνολα γίνονται «έτοιμα για ΤΝ» με λίγη προσπάθεια και ποια δεδομένα λείπουν από την πύλη.
- Φτιάχνει ένα ανοιχτό εργαλείο ελέγχου (web app) που εφαρμόζει τα ίδια κριτήρια σε οποιοδήποτε σύνολο.

Όλη η μέθοδος και κάθε απόφαση καταγράφονται σε αυτό το αποθετήριο, ώστε οποιοσδήποτε να μπορεί να επαναλάβει ή να συνεχίσει τη δουλειά.

## Δομή φακέλων

| Φάκελος ή αρχείο | Τι περιέχει |
| --- | --- |
| `scripts/` | Τα scripts, με τη σειρά που τρέχουν (`00_`, `01_`, …) |
| `data/raw/` | Ό,τι κατεβάζουμε από την πύλη, χωρίς αλλαγές |
| `data/processed/` | Καθαρά αρχεία και βαθμολογίες |
| `criteria/` | Τα κριτήρια αξιολόγησης (`criteria.csv`) |
| `outputs/` | Πίνακες, γραφήματα, αρχεία Croissant, συλλογή RAG |
| `DECISIONS.md` | Κάθε απόφαση, με ημερομηνία και αιτία |
| `requirements.txt` | Οι βιβλιοθήκες Python, με ακριβείς εκδόσεις |

## Πώς το τρέχεις (Windows, PowerShell)

```powershell
git clone <διεύθυνση του αποθετηρίου>
cd datagovgr-ai-readiness
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:PYTHONUTF8 = "1"
python scripts\00_check_setup.py
```

Σε Linux ή macOS: `python3 -m venv .venv` και `source .venv/bin/activate`, και μετά τα ίδια.
