# Reference lists

Controlled vocabularies and other reference lists used by the checks, stored so that the checks can be repeated even if the sources change. Each file names its source and the date of retrieval.

| File | Content | Source | Retrieved |
| --- | --- | --- | --- |
| `eu_file_type.csv` | The EU file-type vocabulary of the Publications Office (233 concepts): code, English label and URI | https://data.europa.eu/api/hub/search/vocabularies/file-type (the copy used by the Metadata Quality Assessment of data.europa.eu); authority table http://publications.europa.eu/resource/authority/file-type | 2026-11-01 |

The theme and frequency vocabularies are not stored: the portal gives these properties as URIs of the EU data-theme and frequency vocabularies, and the checks test the URI prefix. The 25 frequency codes and the 13 theme codes present in the snapshot of 2026-10-24 were verified against the vocabularies on 2026-11-01.
